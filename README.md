# Age Calculator – Python

## Project Overview
The Age Calculator is a Python-based application that calculates a person's exact age from their Date of Birth (DOB). It displays the age in years, months, and days.

This project is developed as part of the Pynexia Tech Python Programming Internship – Week 1 assignment.

## Features
- Calculate exact age in years, months, and days.
- Handle leap years.
- Handle different month lengths.
- Validate invalid date entries.
- Prevent future dates.
- Interactive menu-driven command-line interface.
- Custom exception handling.
- Modular programming using separate Python files.

## Technologies Used
- Python
- datetime module
- calendar module
- Exception Handling
- match-case statement


2. Open the project folder.

3. Run the main Python file:

```bash

```
